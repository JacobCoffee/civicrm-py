About This Demo

This is a demonstration of the civi-py Litestar integration, showcasing:

  • CiviPlugin for dependency injection and auto-generated routes
  • Async views with the shared CiviShowcase module
  • CRUD operations for CiviCRM entities
  • Jinja2 templates for server-rendered UI
  • JSON API endpoints at /api/*
  • OpenAPI documentation with Scalar and Swagger UI
